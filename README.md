# 2026 TI 杯 H 题 钢球闭环小车

基于 MSPM0G3507 与 K230 的管道钢球闭环控制系统。K230 负责视觉识别，MSPM0G3507 负责 50 Hz 舵机控制、底盘运动、任务状态机、参数管理和串口遥测。

## 项目特点

- K230 运行 YOLO11，识别管道内钢球，输出位置、速度和置信度。
- MSPM0G3507 使用位置速度串级控制，包含速度阻尼、加速度反馈、静摩擦补偿和车身加速度前馈。
- TB6612 双电机驱动，编码器轮速 PI，八路灰度循迹，MPU6050 航向闭环。
- 第二至第六问使用独立状态机和参数档，任务之间不共享可调参数。
- 支持按键启动、串口调参、自动整定、OLED 显示和 WHEELTEC 波形输出。
- 具备视觉失联回中、越界急停、按键急停和通信超时保护。

## 快速开始

### 1. 硬件准备

1. 先拆下舵机连杆，避免上电时机构撞限位。
2. 舵机接独立 5 V 电源，所有设备共地。
3. K230 GPIO9 接 MSPM0G3507 PA9，K230 只发送。
4. 调试串口 PA10 和 PA11 接 CH340 或蓝牙模块。
5. 确认灰度模块、MPU6050 和 OLED 接线后再上电。

### 2. K230 部署

当前第三问主脚本是 `k230_ball_tracker/yabo_k230_roi.py`。

1. 把 `yabo_k230_roi.py` 和训练好的 `steelball.kmodel` 放到 K230 的 `/sdcard`。
2. 模型路径保持为 `/sdcard/kmodel/steelball.kmodel`。
3. 固定相机后，用 `MARKER_BOXES` 标定水管四个角点。
4. 确认屏幕上的四边形只覆盖管道，不包含车体和背景。
5. 串口参数为 9600 8N1，K230 每 30 ms 最多发送一帧。

`k230_ball_tracker` 中另外几个文件是不同阶段的版本：

| 文件 | 用途 |
| --- | --- |
| `yabo_k230_roi.py` | 当前第三问主脚本，YOLO11 加四边形区域过滤 |
| `main.py` | 三点标定版本 |
| `ball_yolo11.py` | YOLO11 基础跟踪版本 |
| `ball_fast_test.py` | 不使用 YOLO 的 RGB 快速测试 |

仓库中没有包含 `steelball.kmodel`，需要单独训练和转换。

### 3. MSPM0G3507 编译

1. 用 CCS 重新导入 `F:\ti_终版2` 工程。
2. 确认 `empty.syscfg` 能正常打开，外设和引脚配置无冲突。
3. 编译工程，生成 `Debug/led.out` 和 `Debug/led.hex`。
4. 通过 CCS 或 UniFlash 下载到 LP-MSPM0G3507。

注意：仓库中的 `Debug/makefile` 和旧构建日志仍指向以前的工作目录。换机后不要直接复用旧 makefile，应在 CCS 中重新导入并重新生成构建配置。

### 4. 上电检查

1. OLED 显示 `BT CAR LREV3` 和各任务按键提示。
2. 拆下连杆，用 `n1500` 附近的小步调整找到真实机械中位。
3. 确认 K230 数据有效，OLED 或串口能看到钢球位置。
4. 先手动测试 `a1`、`p0`、`a0`，确认闭环方向和急停都正常。
5. 确认钢球在中心附近后再启动正式任务。

## 任务与按键

| 任务 | 启动键 | 启动条件 | 行为 | 主要限制 |
| --- | --- | --- | --- | --- |
| 第二问 | PA7 | 无 | 循迹一圈，按里程停车并显示计时 | 5989 mm，20 s 超时 |
| 第三问 | PB21 | 钢球在中心 15 mm 内 | 0 到正 50 mm 再到负 50 mm | 到位误差 10 mm，边缘 105 mm 急停 |
| 第四问 | PA26 | 钢球在中心 8 mm 内 | 直线行驶 1500 mm，钢球保持中心 | 8 s 超时，边缘 95 mm 急停 |
| 第五问 | PB9 | 钢球在中心 8 mm 内 | 循迹一圈，钢球保持中心 O 点 | 6589 mm，30 s 计分线，45 s 硬保护，边缘 105 mm |
| 第六问 | PB14 按三次 | 第一次记录目标，第二次预定位，第三次启动 | 循迹一圈，保持启动时指定位置 | 目标范围 115 mm，稳定 2 s 后可启动，边缘 119 mm |

第六问的操作顺序：

1. 把钢球放在目标位置，速度低于 15 mm/s，按一次 PB14 记录目标。
2. 再按一次 PB14，摆杆把钢球推到目标并稳定。
3. 位置误差小于 5 mm 且速度低于 15 mm/s 持续 2 s 后，再按 PB14 启动一圈任务。

## 控制架构

钢球闭环周期为 20 ms，对应 50 Hz。

- 位置外环把位置误差换算成期望滚动速度，并根据剩余距离和制动能力生成速度包络。
- 速度内环使用 PI、速度阻尼和加速度反馈，输出舵机倾角对应的脉宽偏移。
- 静摩擦补偿在低速大偏差时叠加，帮助钢球起步。
- 车身加速度前馈用于抵消小车加减速对钢球的影响，最大 120 微秒。
- 第六问额外使用水平偏置学习和短促助推，处理摆杆不完全水平和局部卡滞。
- 舵机脉宽限制在 1100 到 1900 微秒，正常控制限制在中位附近，终点限位只作保护。

底盘部分：

- 轮速环使用编码器反馈，PI 输出 PWM。
- 灰度循迹输出左右轮差速，第五问按里程限制差速和斜率。
- MPU6050 提供航向角和 Z 轴角速度，用于航向保持和原地转向。
- 停车时 TB6612 进入短接制动，行驶中零输出使用滑行，避免周期性急刹。

## 视觉数据帧

K230 通过串口发送固定 10 字节帧：

```text
AA 55 flags seq position_mm_L position_mm_H velocity_mm_s_L velocity_mm_s_H confidence checksum
```

| 字段 | 说明 |
| --- | --- |
| `AA 55` | 帧头 |
| `flags` | bit0 为 1 表示本帧钢球有效 |
| `seq` | 帧序号，用于统计丢帧 |
| `position_mm` | 小端有符号 16 位，钢球位置 |
| `velocity_mm_s` | 小端有符号 16 位，钢球速度 |
| `confidence` | 置信度，0 到 255 |
| `checksum` | 前 9 字节累加和的低 8 位 |

MSPM0G3507 收到有效帧后更新位置和速度。视觉帧间隔约 60 到 70 ms，控制端保持 180 ms 的上一有效测量以容忍短时漏检；串口连续 200 ms 没有新帧时摆杆回中。位置跳变超过门限的帧不参与控制。钢球到达 119 mm 边缘时锁存急停，必须人工处理。

## 串口调参

调试串口参数为 115200 8N1。常用命令：

| 命令 | 功能 |
| --- | --- |
| `a1` / `a0` | 开启或关闭钢球闭环 |
| `p0`、`p50`、`p-50` | 设置目标位置，单位 mm |
| `n1500` | 设置摆杆水平中位脉宽 |
| `c70` | 设置静摩擦补偿，单位微秒 |
| `3` / `3x` | 启动或中止第三问 |
| `5` / `6` | 启动第五问或第六问 |
| `5x` / `6x` | 中止对应任务 |
| `5s` / `6s` | 查询对应任务 PID 和钢球状态 |
| `5r` / `6r` | 恢复对应任务默认 PID |
| `BP2.400` | 设置第三问位置外环 P |
| `BV0.950` | 设置第三问速度内环 P |
| `BI0.060` | 设置第三问速度内环 I |
| `BD0.350` | 设置第三问速度阻尼 |
| `BSTATUS` / `BDEFAULT` | 查询或恢复第三问参数 |
| `BSTREAM1` / `BSTREAM0` | 开启或关闭 20 Hz 遥测 |

第五问和第六问的独立参数命令使用 `5` 或 `6` 作为前缀，例如 `5p2.400`、`6v0.850`、`5w12.0`、`6k0.45`。

## 自动调参

上位机脚本在 `tools/ball_autotune.py`，只通过 MCU 调试串口通信，不直接控制任何引脚。

```powershell
py -3 tools\ball_autotune.py --list-ports
py -3 tools\ball_autotune.py --port COMxx
```

脚本使用受限坐标下降，默认最多 11 次试验。每次试验前会发送 `BSTOP`，并要求人工把钢球放回 O 点后确认。结果保存在 `tools\autotune_runs\时间戳\`，包括每轮 CSV 和 `best_params.json`。自动调参结果只保留在 RAM，重新上电后恢复固件默认值。

## 遥测与波形

第五问和第六问启动后，调试串口会以 20 Hz 输出 WHEELTEC 波形帧：

```text
{Btime_ms:state:distance_mm:target_rpm:measured_rpm:line_error:task_value:ball_mm:ball_velocity_mm_s:servo_control_us}$
```

第五问通道 6 是左右轮实测差速，通道 4 是平均轮速，可以还原左右轮速：

```text
left = average + difference / 2
right = average - difference / 2
```

第三问自动调参还支持 CSV 遥测，字段顺序和通道说明见 `tools` 目录下的文档。

## 安全说明

- 首次调试必须拆下舵机连杆。
- 先确认机械中位，再装回连杆。
- 钢球闭环开启时不要把手放在摆杆运动范围内。
- 出现异常时按 PB21 急停，或发送 `3x`、`5x`、`6x`。
- 视觉失联时摆杆会回中，但越界急停会锁存，必须人工把钢球移回安全区并重新启动。
