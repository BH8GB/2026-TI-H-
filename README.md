# 2026-TI-H-
2026年TI杯H题重庆市省一作品
本项目为2026年TI杯H题钢球闭环小车，主控采用MSPM0G3507，视觉采用K230。K230运行YOLO11识别水管内钢球，以十字节串口帧发送位置、速度和置信度。主控以五十赫兹驱动摆杆舵机，使用位置速度串级控制，并加入速度阻尼、加速度反馈、静摩擦补偿和车身加速度前馈。底盘由TB6612、编码器、八路灰度和MPU6050组成，完成轮速PI、循迹和航向闭环。固件将第二至第六问拆为独立状态机和参数档，支持按键启动、串口调参、自动整定、OLED显示和多重故障保护，包括视觉失联回中、越界急停和按键急停。开源内容含MSPM0固件、K230脚本、上位机工具及接线文档。当前尚未添加许可证，第六问实现并入第五问源文件。
